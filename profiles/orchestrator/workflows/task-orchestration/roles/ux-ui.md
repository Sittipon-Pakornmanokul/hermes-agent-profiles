# ux-ui handoff supplement

Set checkpoints for user-goal brief, low-fidelity end-to-end flow, then scoped prototype and evidence. Defer visual variants/polish until the core journey is specified. Reuse existing design patterns and tokens. Deliver artifacts and coverage for the independent critic; preserve responsive/accessibility and recovery checks.

Use the shared handoff fields. Return acceptance evidence and unresolved items; include a receipt path only when measurement is requested. Do not invent metrics.
