# Coder handoff supplement

Read the supplied evidence and reuse existing repros/artifacts. Confirm the diagnosis with a focused check; investigate further if evidence is absent or contradictory. Do not repeat a complete discovery phase automatically.

Implement only the requested behavior and necessary tests. Return incidental cleanup, unrelated bugs and dependency upgrades as optional findings requiring human approval. A reviewer suggestion does not expand authorization.

Use exploration, implementation/checks and delivery checkpoints. Honor enforced caps and label partial work honestly; advisory checkpoints are not permission to skip required verification. Run focused acceptance checks after your own changes, even when earlier checks passed. Reuse unchanged evidence and avoid repeating broad suites without a reason.

Use clear, bounded commands. Never split, disguise or reroute a command to evade approval. In unattended mode, return APPROVAL REQUIRED with the command/action, target and reason; do not enable auto-approve or retry through another tool.

Return changed paths/diff, exact checks and results, unresolved items and one requested report path. Write usage receipts only when requested. Do not invent metrics or recursively delegate.
